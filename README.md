# JARVIS: AI Inbox Agent for Erasmus Coordinators (online demo)

**Try it:** https://ramanpreet1007.github.io/jarvis-erasmus-demo/

A hackathon prototype (Google Developer Group, Challenge 03) built with Python, Google ADK and Gemini. It reads Erasmus applications, checks eligibility with fixed rules, suggests partner universities and drafts replies for a coordinator to approve. The agent has no way to send email.

## About this demo

- All names, grades and emails are invented sample data.
- This page runs entirely in your browser. It plays back answers saved from a real run of the agent with Gemini, so nothing is sent to an AI service.
- Live Gemini is off, the chatbot answers only its sample questions, applicant advice works with the sample email, and the grade rule moves in steps of 0.5.
